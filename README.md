# Aneesh Nandigrami | Portfolio

A responsive personal portfolio website for Aneesh Nandigrami, a Full Stack Developer. The site presents personal information, technical skills, selected projects, education, resume links, and a contact form.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Animated loading screen
- Typed developer role animation
- Interactive particles background
- Smooth section navigation
- Active navigation state while scrolling
- Skills and performance section
- Project showcase with live project links
- Education timeline
- Resume view and download actions
- Contact form powered by EmailJS
- Toast notifications for form status messages
- Reduced-motion support

## Getting Started

This is a static website and does not require a build step or package installation.

1. Clone or download this repository.
2. Open `home.html` directly in a browser.

For a better local development experience, open the folder in VS Code and use the Live Server extension.
